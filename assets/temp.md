## 【译文】

我认为，一个情况有力地证实了上述最后一个观念：即在*托马斯·库恩*（_Thomas Kuhn_）关于科学革命之本性与特征的理论中，我们实际上发现了逻辑经验主义者所发展出的那种*相对化的构成性先天原则观念*（_relativized conception of constitutive a priori principles_）的一个*非形式对应物*（_informal counterpart_）。

因此，库恩关于*范式变革或革命性科学*（_change of paradigm or revolutionary science_）与另一方面*常规科学*（_normal science_）之间的核心区分，与卡尔纳普关于*语言或语言框架的变革*与*在这样一个框架之内所进行的受规则支配的运作*之间的区分密切平行。

- 正如对卡尔纳普而言，一个语言框架的*逻辑规则*（_logical rules_）*定义或构成*（_definitive or constitutive_）了相对于此框架的"*正确性*"或"*有效性*"（_correctness or validity_）之概念；同样地，对库恩而言，*一个支配着某一常规科学状态或阶段的特定范式*，也产生出了一些*普遍同意的（尽管可能只是心照不宣的）规则*，这些规则*定义或构成*了在该常规科学状态之内什么算作对某一问题的"*有效*"或"*正确*"解答；
- 正如对卡尔纳普而言，关于*该采纳哪一个语言框架*的*外部问题*（_external questions_）并不以同样的方式受逻辑规则支配，而是需要一种*远不那么确定的*、诉诸*约定与/或实用考量*（_conventional and/or pragmatic considerations_）的诉求；同样地，对库恩而言，*革命性科学中的范式变革*并不像常规科学那样按照普遍同意的规则进行，而是需要某种*更类似于"皈依经验"（_conversion experience_）*的东西。

## 【解析】

这一段是全书*最重要的历史论断之一*，也是 Friedman 论证策略的*关键收束*。他要在此确立一个可能令许多读者感到意外的*结构性同构关系*：*卡尔纳普和库恩，尽管来自完全不同的哲学传统、使用完全不同的方法论，实际上在描绘同一种基本图景。*

这个论断如果成立，就产生了一个惊人的哲学后果：*卡尔纳普 vs. 库恩的对立*——在标准的哲学史叙事中，这被视为20世纪科学哲学中"形式主义 vs. 历史主义"的根本对立——*实际上是一个假问题*，两者其实是同一个"相对化构成性先天"图景的两种表述方式。

### 1. 平行结构的精确刻画

让我们把 Friedman 建立的平行关系画成一张对照表，以便更清晰地把握：

| | *卡尔纳普*（形式化的） | *库恩*（历史化的） |
|---|---|---|
| *稳定/常规阶段* | 在一个已经采纳的*语言框架*内运作 | 在一个已经确立的*范式*内运作（常规科学） |
| *稳定阶段的规则性质* | 由*逻辑规则*明确规定的、*受规则支配*的运作 | 由范式产生的、*普遍同意的（尽管可能只是心照不宣的）规则* |
| *规则的功能* | 定义/构成"正确性"和"有效性" | 定义/构成什么算"有效"或"正确"的问题解答 |
| *规则的地位* | *构成性的*（不是可修正的经验命题） | *构成性的*（不是可修正的经验命题） |
| *框架/范式的转换* | *外部问题*：采纳哪个语言框架？ | *革命性科学*：从一个范式转到另一个范式 |
| *转换的性质* | *不受*逻辑规则支配 | *不按*普遍同意的规则进行 |
| *转换如何进行* | 诉诸*约定或实用考量* | 需要类似*"皈依经验"*的东西 |

*这个平行关系的深度*极为惊人。它不是表面的类比，而是*结构上的同构*：

- 两者都区分了*框架/范式内部*（受规则支配的稳定活动）与*框架/范式转换*（不受规则支配的革命性活动）；
- 两者都认为框架/范式内部的规则*构成*（而不仅仅是描述）该阶段的正确性标准；
- 两者都认为框架/范式转换*无法*被同样的规则支配，因而需要*根本不同性质*的证成方式。

### 2. "心照不宣的规则"——库恩的关键补充

Friedman 注意到一个微妙但重要的差异：

- *卡尔纳普的规则*是*明确的、形式化的*——它们是在语言框架的构造中被*明文规定*的（L-规则、P-规则、语义规则等）；
- *库恩的规则*是"*普遍同意的（尽管可能只是心照不宣的）*"（_generally agreed upon (although perhaps only tacit)_）——它们不需要被明确写下来，科学家在实际的科学实践中"心知肚明"地遵守它们。

这个差异不是本质性的，而是*形式化程度*的差异。库恩的"心照不宣的规则"完全可以在原则上被明确形式化——只是在实际的科学实践中，科学家们通常不这样做（他们通过范例、教科书、师徒传承来"隐性地"掌握这些规则）。

请注意 Friedman 用词的精心：他说库恩的理论是逻辑经验主义相对化先天观念的"*非形式对应物*"（_informal counterpart_）。这个"informal"（非形式）恰恰刻画了这个差异——*库恩不是与卡尔纳普对立，而是卡尔纳普的历史化/实践化版本*。

### 3. "皈依经验"（conversion experience）——一个需要仔细理解的术语

Friedman 特别提到，库恩把范式转换比作"*皈依经验*"（_conversion experience_）——这是一个宗教术语，指一个人从一种世界观（比如无神论）*突然*转向另一种世界观（比如宗教信仰）的经历。

*为什么库恩使用这个类比？*

因为在范式转换中：
- 不存在*共享的中立标准*可以让两个范式之间进行"理性对话"；
- 转换涉及*整个世界观的重构*，而不仅仅是某些具体信念的修改；
- 转换往往是*格式塔式的*——不是一步步的推理，而是"看世界的方式"的突然转变；
- 转换的*接受*不能通过纯粹的逻辑论证来强制。

*库恩这个比喻的争议性*：

这个"皈依"比喻是库恩理论中*最有争议的部分*之一。它似乎暗示：
- 范式转换是*非理性的*（就像宗教皈依不能被逻辑证明一样）；
- 不同范式之间是*不可通约的*（不同宗教之间没有共同基础）；
- 科学革命更像*社会心理学现象*而非*认识论现象*。

这就是为什么后来许多哲学家（包括奎因的追随者）把库恩解读为*相对主义者*或*非理性主义者*。

*Friedman 对此的立场*（这是全书的关键）：

Friedman 明确不接受库恩的相对主义解读。他的策略是：
- *承认*范式转换不像常规科学那样由明确规则支配；
- *但拒绝*由此推出转换是非理性的；
- 转换的理性性质需要一种*不同的*证成方式——不是通过范式*内部*的规则，而是通过*元框架层次*的哲学反思（即第一讲末尾我们读到的"元框架"概念）。

这也回答了您上一个问题中提出的深刻挑战：Friedman 关于"框架转换的理性依据"这个新的 _quid juris_ 问题，将在第三讲中通过"探究共同体"和"元框架"理论来处理。而这里，他先要*建立*卡尔纳普-库恩的结构同构，为下一步的论证铺路。

### 4. 这个论断的历史反讽（再次浮现）

我们已经多次遇到 Friedman 揭示的*历史反讽*，这里又是一个：

*标准的哲学史叙事*：
- 卡尔纳普 = 形式化、非历史的、"科学的哲学"传统的顶峰；
- 库恩 = 历史化、社会学化、*对形式化传统的攻击*；
- 两者代表20世纪科学哲学中根本对立的两极。

*Friedman 的重新解读*：
- 卡尔纳普和库恩实际上在做*同一件事*——描绘"相对化构成性先天原则"的图景；
- 两者的差异只是*方法论上的*（形式化 vs. 历史化）、不是*实质性的*；
- 库恩不是卡尔纳普的*掘墓人*，而是他的*盟友和补充*。

回忆我们在第一讲中读到的历史细节：*库恩的《科学革命的结构》是由卡尔纳普亲自主编、出版在他所领导的《统一科学国际百科全书》中的！* 卡尔纳普对库恩的工作*极为热情*——这个事实在标准叙事中被视为"卡尔纳普没有意识到自己被库恩打败了"，但在 Friedman 的重新解读中，恰恰说明*卡尔纳普是对的*：他从库恩身上看到了自己思想的历史学同盟。

这个反讽为 Friedman 的哲学计划提供了*思想史的正当性*：他的"动态先天论"不是一个凭空发明的新学说，而是*卡尔纳普和库恩共同预示的图景*的自觉化和系统化表述。

### 5. 一个非常微妙的哲学后果

如果 Friedman 建立的这个卡尔纳普-库恩平行关系成立，那么它就产生了一个非常微妙的哲学后果：

*奎因对卡尔纳普的攻击*（分析/综合区分的崩溃），*并没有*同时摧毁卡尔纳普思想的核心洞见（构成性先天原则的存在）。因为：

- 库恩用*完全不同的方法论*（历史考察）*独立地*到达了卡尔纳普的核心图景；
- 库恩的方法论不依赖于"分析/综合"这个词汇或形式定义；
- 因此，即使奎因对"分析性的形式定义"的攻击是成功的，卡尔纳普的*核心图景*（分层结构 + 构成性原则 + 框架转换）仍然通过库恩的历史化版本*存活下来*。

这就在*方法论层面*印证了 Friedman 上一段的核心论点：*"定义的失败"不等于"现象的不存在"*。卡尔纳普对分析性的形式定义失败了，但他试图刻画的*现象*（构成性先天原则）通过库恩的历史化版本*得到了独立的确认*。

### 6. 与前面讨论的深层呼应

这一段还与我们前面的讨论形成多层呼应：

*与您关于 Friedman "退缩"的诊断的呼应*：

您上一段问：如果 Friedman 从"先验奠基"退到"历史展示"，那这是否是一种哲学上的退缩？现在这一段实际上暗中回答了这个问题：*Friedman 的"历史展示"不是任意的、没有哲学地位的*——它是*通过库恩的科学史研究*独立地到达了卡尔纳普通过形式方法试图达到的同一个结构。也就是说：

> 库恩的历史考察和卡尔纳普的形式分析，是*从两个方向汇聚到同一个结构*（相对化构成性先天）的两条路径。这不是"用历史事实替换先验奠基"，而是*用双重的独立方法来展示同一个哲学现象*。

如果这个论断成立，那么 Friedman 的"退缩"就不是您所担心的那种哲学退让——它有其独立的哲学正当性，因为它建立在*卡尔纳普和库恩独立会合*这个坚实的思想史事实之上。

*与前面反驳奎因论证的呼应*：

奎因用相对论革命作为论据来反对先天原则。Friedman 在前几段中论证：相对论革命恰恰*展示了*构成性先天原则的存在（黎曼几何 → 等效原理 → 场方程的分层结构）。现在这一段进一步论证：*库恩关于科学革命的整个理论*——如果被正确理解——*本身就是*相对化先天观念的历史学表述。所以奎因用来反对先天的证据（科学革命），既在结构分析上（Friedman 的分层分析），也在思想史上（库恩的范式理论），都反过来支持先天。

### 7. 一个战略性的观察

Friedman 在这里做的事，可以被理解为*为"动态先天论"寻找双重的历史支撑*：

```
逻辑经验主义传统（卡尔纳普）：
提供了"相对化先天"的形式化表述
        ↓
    结构同构
        ↓
历史主义传统（库恩）：
提供了"相对化先天"的历史化表述

Friedman 的"动态先天论"：
= 卡尔纳普的形式洞见 + 库恩的历史洞见
= 两条独立路径汇聚的结果
```

这样，Friedman 的立场就获得了双重的正当性：
- 它继承了逻辑经验主义传统中"构成性分层"的核心洞见（反对奎因整体论）；
- 它同时吸收了历史主义传统中"框架历史演化"的核心洞见（反对静态先天论）；
- 而卡尔纳普-库恩的结构同构证明：这两个洞见*不是*对立的，而是*同一个真理的两个方面*。
