## 译文

然而，重要的是要认识到，这种强烈的*反先天主义*（*anti-apriorist*）的科学知识观，在十九世纪末和二十世纪初——也就是我们今天与爱因斯坦相关联的几何学和力学的伟大革命实际发生的那个时期——*绝非*主流观念。就亥姆霍兹的情形而言，尽管他确实把欧几里得几何与非欧几何之间的选择视为一个经验问题，他同样也提出：两种几何系统所共有的更一般的空间结构——即*常曲率*（*constant curvature*）的结构，亦即亥姆霍兹所谓的"*自由移动*"（*free mobility*）——是一切空间测量的*必要预设*，因而是我们空间直观的一种康德意义上的"*先验的*"形式。而庞加莱又在此基础上走得更远。尽管没有任何特定的几何学——无论是欧几里得的还是非欧几里得的——是我们空间直观的先天条件，但这并不意味着在这些几何学之间的选择是一个经验问题。因为在我们粗糙而近似的感觉经验与我们对自然的精确数学描述之间，仍然存在着一道不可消除的鸿沟。庞加莱论证说，确立这种或那种几何体系，因此需要一种*自由的选择*，一种*我们自身的约定*——这种约定最终建立在欧几里得体系更大的数学简洁性之上（庞加莱去世时广义相对论尚未被创立）。【原注㉝】

*【原注㉝】* 关于亥姆霍兹和庞加莱的详尽讨论——包括他们与康德以及逻辑经验主义者的关系——参见 Friedman (1999, 第四章)、(1997b)、(2000a)。

## 解析

这段话是第二讲的一个*历史转折点*。在此之前，Friedman 一直在描述"非欧几何的出现如何动摇了康德的先天综合观念"。但这一段告诉我们一个极重要的历史事实：*当时在场的哲学家和科学家，并没有因为非欧几何的出现就立刻得出奎因式的"无先天元素"结论。* 相反，他们提出了各种更细致的方案，试图保留某种修正版的先天性。这正是 Friedman "相对化先天论"的直接思想史来源。

### 1. 亥姆霍兹的两层应对

亥姆霍兹的立场颇为微妙。他在*两个不同层次*上分别做出了不同的判断：

*第一层（具体几何的选择）：经验的*

亥姆霍兹认为，"空间是欧氏的"还是"空间是非欧的"，是一个可以被实验检验的经验问题。他的生理光学和感知研究表明，我们对空间的直觉其实来自经验积累，而非康德所说的纯粹先天直观。因此，具体的几何类型（欧氏/双曲/椭圆）是*后天可修正的*。

*第二层（更一般的结构）：先天的*

但亥姆霍兹并未因此走向彻底的经验主义。他注意到一个关键事实：欧氏几何和非欧几何（常曲率几何）之间，存在一个*共同的更高层次结构*，即*"自由移动"（free mobility）*原理。

*什么是"自由移动"？*

"自由移动"是说：在几何空间中，一个刚体（rigid body）可以从任意一个位置、朝任意方向自由移动到另一个位置，而不改变其形状和大小。

在不同曲率空间中（欧氏平面、球面、双曲面），"刚体"都可以自由移动——这是所有常曲率几何的共同特征。而在非常曲率的弯曲空间中（比如广义相对论的时空），刚体不能自由移动，因为不同位置的曲率不同，移过去的"刚体"会被拉伸或压缩。

亥姆霍兹的论点是：*要进行任何空间测量，首先必须预设存在刚体，以及刚体可以自由移动。* 没有这个预设，"测量"本身就失去了意义（你没有可以搬来搬去的标准尺子）。

因此，"自由移动"是*所有可能的空间测量的必要条件*——在这个意义上，它是康德所说的"先验的"形式，是经验之可能性的条件，而不是从经验中归纳出来的。

*亥姆霍兹方案的结构：*

```
第二层（先天的）：自由移动原理（使测量成为可能）
                 ↓
第一层（后天的）：具体曲率是多少？（欧氏？双曲？——经验决定）
```

这已经是一种初步的*"相对化先天"*：不是"欧氏几何先天"，而是"更一般的测量框架先天"。这个思路与 Friedman 自己的方案非常接近。

### 2. 庞加莱：从亥姆霍兹出发，再推进一步

庞加莱接受了亥姆霍兹的基本直觉，但做了更激进的推进：

*庞加莱的起点*：我们的感觉经验与精确数学描述之间有一条*不可消除的鸿沟*。

这个鸿沟是什么意思？

当我们用尺子测量一段距离，得到"这段距离是1米"的时候，这个结论已经包含了大量*隐性的预设*：
- 我们的尺子是"刚性的"（不受热膨胀、压力等影响）；
- 我们定义的"直线"是某种意义上的最短路径；
- 我们选择了某种坐标系来描述位置。

这些预设不是经验给我们的，而是*我们加进去的*。庞加莱说，这就是为什么几何学不是经验科学：它无法被经验单独决定。

*庞加莱的三角鸿沟论证：*

```
感觉经验（粗糙、近似）
         ↓ 无法直接跨越
精确数学描述（精确、严格）

中间需要约定（conventions）作为桥梁
```

*庞加莱的约定论（Conventionalism）：*

庞加莱说，几何学的选择既*不是先天必然的*（反驳康德），也*不是经验决定的*（反驳亥姆霍兹），而是*约定的*——我们根据*方便性（simplicity）*自由选择一套几何语言，然后相应地调整物理定律来描述实验结果。

*约定论的一个经典例子：*

设想测量三角形的内角和。
- 如果我们采用*欧氏几何*，并且发现测量结果不是180°，我们可以说：这是因为有某种"扭曲力"（相当于广义相对论中的引力场）影响了光线路径。
- 如果我们采用*非欧几何*，同样的测量结果可以被解释为：空间本来就是弯曲的，三角形内角和不是180°是正常的。

两种解释在经验上都是相容的！你无法通过纯粹的经验实验来区分它们，因为改变几何选择后你也改变了"力"的定义。

庞加莱的结论：*选欧氏几何还是非欧几何，不是事实问题，而是约定问题。*

他自己的立场是：欧氏几何在数学上最简单，所以我们选择它——这是一个*便利性的约定*，不是真理的发现。

### 3. 庞加莱没有活到看见广义相对论

文中一个括号说明极为重要：*"庞加莱去世时广义相对论尚未被创立"*（庞加莱1912年去世，广义相对论1915年完成）。

这是一个令人深思的历史遗憾。庞加莱的约定论有一个潜在的盲点：他假定我们可以*无代价地*在不同几何之间切换（只要相应调整物理定律）。但广义相对论表明，当我们选择*黎曼几何*并将其与等效原理结合时，整个理论在*统一性、简洁性、预测能力*上远远优于"欧氏几何+额外的力场"方案。

也就是说，庞加莱是对的：几何选择不是纯粹的经验问题。但他低估了*几何选择与物理理论的深度耦合*——某些几何选择会比其他选择导致更深刻的理论统一性。这正是 Friedman 要进一步发展的方向：约定不是完全随意的，某些约定（构成性先天原则）比其他约定在理性上更优越。

### 4. 三种立场的比较图景

```
康德（原初）：
欧氏几何 = 先天综合，永恒必然，对所有可能经验有效
                     ↓ 被非欧几何动摇

亥姆霍兹：
具体几何类型 = 后天经验决定
更一般的"自由移动"结构 = 先天（更高层的必要预设）

庞加莱：
任何具体几何 = 不是先天的，也不是后天的，而是约定的
约定的依据 = 数学简洁性（便利性）

Friedman（将要展开）：
约定不是任意的
某些先天框架在科学革命中被理性地替换为另一些
替换是有理性标准的（统一性、包容旧理论、消除不可观测结构）
```

### 5. 这段在全书中的战略位置

这段话是 Friedman 整个第二讲论证的*关键历史节点*。它告诉我们：

- 反先天主义（奎因式）*不是*历史上对非欧几何冲击的自然反应；
- 历史上真正在场的哲学家（亥姆霍兹、庞加莱）都*保留了某种先天性*；
- 他们的方案虽然不同，但都试图在"康德太强"与"奎因太弱"之间找到中间道路；
- Friedman 自己的"相对化先天论"正是从这个历史传统中提炼出来的。

换言之，Friedman 在这里给我们看的是：*动态先天论不是凭空发明的，而是19世纪末20世纪初科学哲学发展的自然产物*——只是奎因不恰当地把这段历史解读为"先天性的全面崩溃"，而 Friedman 要展示它实际上是先天性的*精炼与相对化*。
